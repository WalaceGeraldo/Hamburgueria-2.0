# Hamburgueria 2.0 🍔

Bem-vindo à **Hamburgueria 2.0**, uma aplicação web moderna e responsiva para gerenciamento e pedidos de uma hamburgueria artesanal. Este projeto inclui uma interface para clientes realizarem pedidos e um dashboard administrativo para gestão de vendas e produtos.

## 📋 Funcionalidades

### Para Clientes
-   **Cardápio Interativo**: Visualização de hambúrgueres, acompanhamentos e bebidas com fotos e descrições detalhadas.
-   **Carrinho de Compras**: Adição e remoção de itens, cálculo automático de total e checkout.
-   **Checkout**: Formulário para finalização de pedido com opção de entrega e retirada.
-   **Design Responsivo**: Experiência otimizada para desktops, tablets e smartphones.

### Para Administradores (Dashboard)
-   **Visão Geral**: Métricas em tempo real de vendas e faturamento.
-   **Gestão de Pedidos**: 
    -   Visualização de lista de pedidos recentes e histórico completo.
    -   Alteração de status (Pendente, Entregue, Cancelado).
    -   Visualização detalhada do pedido e endereço de entrega (integração com Google Maps).
    -   **Exclusão Individual**: Remova pedidos específicos da visualização do painel.
    -   **Limpar Tudo**: Opção para limpar o painel mantendo o histórico.
-   **Gestão de Produtos**: Adicionar, editar e remover itens do cardápio.

## 🚀 Tecnologias Utilizadas

-   **HTML5 & CSS3**: Estrutura semântica e estilização moderna (Dark Mode, animações).
-   **JavaScript (Vanilla)**: Lógica do frontend, manipulação do DOM e gerenciamento de estado local.
-   **LocalStorage**: Persistência de dados (pedidos, carrinho e produtos) no navegador, simulando um banco de dados.
-   **FontAwesome**: Ícones vetoriais.
